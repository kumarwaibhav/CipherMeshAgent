# Assignment 2.2: Distributed Agent Messaging using Sockets/RPC Communication

**Objective.** Let agents send and receive typed messages over the network.

## What was delivered

- Raw TCP client–server messaging with length-prefixed frames.
- Two-terminal scenario: Agent-A transfers typed policy state to Agent-B, which validates, applies and acknowledges it.
- Signed, time-limited messages with replay protection.
