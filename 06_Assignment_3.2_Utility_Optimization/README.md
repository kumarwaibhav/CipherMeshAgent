# Assignment 3.2: Self-Interested Agent Utility Optimization for E-Commerce

**Objective.** Formulate an explicit utility function and choose the optimal option under constraints.

## What was delivered

- Weighted utility function over quality, cost, delivery, reliability and returns.
- Hard constraints filter out infeasible options (budget, stock, region, quality, reliability).
- Out of 10 options, 6 were feasible; ECO-08 (NorthPeak) was selected with utility 71.24.
